# Importar banco no cPanel / phpMyAdmin

Use o arquivo **`geekhost-cpanel-import.sql`** (sem comentários `--`, para não quebrar no phpMyAdmin).

1. Crie o banco MySQL e associe o user `geek6923_banco`.
2. No phpMyAdmin, **selecione o banco**.
3. Aba **Importar** → escolha `geekhost-cpanel-import.sql` → Executar.
4. Não cole o SQL na aba SQL se o editor juntar linhas; prefira **Importar arquivo**.

Admin padrão:

- URL: `https://geekhost.com.br/admin/login`
- Email: `admin@geekhost.com.br`
- Senha: `GeekHost@Admin1`
